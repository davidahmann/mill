# Mill v0.6.0

`0.6.0` is the next public-alpha candidate. It adds a read-only guided proposal
command, a redacted local report, a fixed-name optional shipper-token reference,
a fixture-only second-repair experiment, a smaller package export surface, and
early validation of qualification JSON.

## Candidate scope

`millctl init propose` reads existing repository planning material and returns a
single review summary. It cannot create authority, approve a proposal, call a
model, push a branch, open a pull request, merge, tag, or publish.

`millctl report` returns local aggregates only. It omits task identifiers,
paths, prompts, credentials, raw logs, event payloads, review text, and delivery
receipts. A declared self-hosting rate reports managed local runs; it does not
measure customer value or engineering productivity.

The optional shipper credential setting accepts only the `MILL_GITHUB_TOKEN`
environment variable name. Mill passes the token only to attended GitHub and Git
processes. It does not store, display, log, or send it to a worker. Token scope
and expiry remain the operator's responsibility.

One named fixture may request two repair generations. Normal tasks retain one.
Mill repeats validation and review after each repair. This release does not add
container isolation, a second model, a GitHub App, a daemon, a central MCP
service, automatic release action, or broader stack support.

## Prepublication record

This file is part of the immutable release candidate. It records intended scope
before tag creation and publication. The tagged copy will not be rewritten with
provider results. Later release closure records will name the candidate and
publish workflow runs, preserved artifact identity, npm tags, and GitHub Release
readback.

The earlier `v0.5.0` tag remains failed prepublication evidence. Its candidate
rejected malformed manually constructed JSON before npm publication or GitHub
Release creation. `v0.6.0` uses the parser and encoder added in this release to
avoid reusing that candidate or its input construction.

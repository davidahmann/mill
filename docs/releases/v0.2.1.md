# Mill v0.2.1

Published and read back on 2026-09-05. Both npm `alpha` and `latest` point to
`0.2.1`; GitHub Latest also points to this version. Mill remains a qualified
public alpha, not a general enterprise production-readiness certification.

This release includes the architecture follow-through prepared for `0.2.0`:
source-backed follow-up task compilation, bounded brownfield context,
experimental native Node adoption, complete-diff review, bounded validation
repair, and separately approved attended merge plans. Draft-only remains the
default; builders and reviewers never receive forge mutation authority.

The `v0.2.0` tag is retained as prepublication evidence. Its npm publication was
held after a missing publish-runner image preflight was found. This version
explicitly prepares the digest-pinned verifier on every fresh full-canary
runner, before publication. A native policy gate guards that order. Runtime
behavior, the recipe and its acceptance oracles are unchanged by this repair.

## Install

```sh
npm install --save-dev --ignore-scripts @davidahmann/mill@0.2.1
npx --no-install millctl --version
```

Existing repositories must deliberately update their Mill version pin and
requalify. Native Node ESM/npm adoption remains experimental, not
arbitrary-stack or pnpm support. Legacy reviews without full-diff scope cannot
certify new delivery. Keep v0.1.5 artifacts as the trust root; never move
released tags or assume an older binary can interpret newer approval state.

Known maintainer-disposition P2: run `state purge` from a surviving original
checkout, not an authority worktree scheduled for deletion. Committed output is
retained on its Git branch; using the deletable worktree as the command root can
leave cleanup incomplete.

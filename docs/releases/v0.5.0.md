# Mill v0.5.0

`0.5.0` is a public-alpha release candidate. It adds explicit local-state
migrations, redacted aggregate lifecycle statistics, clearer operator guidance,
and focused migration, JSON-contract, and path-safety regression coverage.

The migration ledger upgrades supported local v1 and v2 state to v3. It does not
introduce a general migration framework, automatic rollback, a second worker,
expanded repair budget, container isolation, a daemon, an MCP service, or new
delivery authority.

## Install after publication

```sh
npm install --save-dev --ignore-scripts @davidahmann/mill@0.5.0
npx --no-install millctl --version
```

Pin the exact version. A dist-tag is a distribution pointer and never an
automatic-update instruction for an existing repository.

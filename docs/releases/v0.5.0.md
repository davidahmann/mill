# Mill v0.5.0

`0.5.0` was a public-alpha release candidate. It added explicit local-state
migrations, redacted aggregate lifecycle statistics, clearer operator guidance,
and focused migration, JSON-contract, and path-safety regression coverage.

The migration ledger upgrades supported local v1 and v2 state to v3. It does not
introduce a general migration framework, automatic rollback, a second worker,
expanded repair budget, container isolation, a daemon, an MCP service, or new
delivery authority.

## Failed prepublication state

The source change merged in PR #48. Its exact candidate passed the native
checks, package canary, structural audit, and protected pull-request checks. The
annotated `v0.5.0` tag reached the candidate workflow. Its two independent
builds and packed canaries passed. Qualification then failed before publication:
the manually constructed workflow input appended the literal characters `\n`
after a JSON object, so the qualification parser rejected it. No npm package or
GitHub Release was created, and `latest` and `alpha` remain `0.4.0`.

The failed candidate, tag, run, and artifact evidence remain preserved. Release
rules prohibit changing the tag or reusing the candidate after this failure. A
new reviewed `v0.6.0` candidate uses a script that parses and re-encodes both
qualification JSON inputs before dispatch.

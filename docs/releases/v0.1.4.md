# Mill v0.1.4 package-identity bootstrap

This candidate passed local and GitHub-hosted release qualification. Its exact
preserved tarball was then published to npm under the `bootstrap` tag using the
maintainer's interactive 2FA session, solely because npm requires the package to
exist before a trusted publisher can be configured.

Registry bytes, signature, clean install, CLI version, and help read back
correctly. The publication has no CI provenance or GitHub Release, so `v0.1.4`
is not the supported public alpha. The protected GitHub environment and npm OIDC
binding were configured immediately afterward; the complete release chain
continues under `v0.1.5`.
